## Что нового в 0.7.0

- Раздел «Обновления» в панели: проверка новой версии и обновление одной кнопкой. Если новая версия не заработает, вернётся прежняя.
- Команда на сервере: `awg-cascade update`.
- При новой установке YouTube сразу идёт с сервера 1 через tpws, способ «Разрезание на TLS-записи». Этот способ теперь первый в списке.
- После перезапуска панели вход сохраняется.

Новая установка на сервере 1:

```
curl -fsSL https://raw.githubusercontent.com/morphing888/FineVPS/main/install.sh | sudo bash
```
