# Грабли

- Команда `curl | bash` читает скрипт из канала, поэтому весь `install.sh` лежит внутри функции, а дочерние программы получают `</dev/null`, иначе они съедят остаток скрипта.
- Пароль для ssh передаётся через `SSH_ASKPASS` и переменную окружения процесса: он не попадает в параметры, файлы и журнал. Имя переменной не начинается с `AWGC_`, потому что стенд пересылает такие переменные на сервер 2.
- `ssh-keygen` и вход по ключу должны идти до пароля: при обновлении пароль уже не нужен и в панели его взять неоткуда.

- tpws в прозрачном режиме нужен запуск от root: он сам сбрасывает права. Поэтому `DynamicUser` есть только у ByeDPI.
- Ключи WireGuard заканчиваются на `=`. Разбор через `awk -F=` отрезает этот знак, поэтому ключи берутся через `sed`.
- При отказе новой программы обхода нельзя оставлять старые правила: перенаправление на остановленный прокси оборвало бы YouTube. Для этого есть `yt_fallback`.
- На стенде PID 1 не убирает завершённые процессы, и `kill -0` видит их как живые. Проверка смотрит состояние процесса.

- `#logout` имел класс `.tab`, и общий обработчик вкладок заменял его действие. Вкладки выбираются по `.tab[data-page]`.
- SVG-фильтр с областью по рамке элемента скрывает прямые линии: у них нулевая высота. Нужен `filterUnits="userSpaceOnUse"`.
- Перерисовка графика при открытой подсказке оставляет её висеть. Пока подсказка открыта, графики не перерисовываются.

- nfqws2 читает файл настроек через wordexp: знаки `<`, `(`, `|` без кавычек ломают запуск.
- Пока подбор не запускался, панель не должна писать «обход не найден».

- В `.chart svg` стили попадали и на значки легенды, поэтому легенда разъезжалась. Теперь правило только для прямого потомка.
- `cat >файл` не перезаписывает работающую программу на сервере 2 (Text file busy). Файл копируется во временный и переносится через `mv`.

- `rp_filter=1` молча отбрасывает ответы из туннеля: они приходят с адресов, чей обычный маршрут идёт через внешний интерфейс. Рукопожатие при этом есть, а сайты не открываются.
- Если интерфейс туннеля пропал, правило маршрутизации проваливается в основную таблицу, и зарубежный трафик уходит с российского IP. Поэтому в таблице есть запасной маршрут `unreachable`.
- При перезапуске туннеля маршрут через него исчезает из таблицы. Его возвращает `PostUp`.
- В `awg-quick` строка `# имя` внутри `[Peer]` безопасна: это комментарий.
